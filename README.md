#  Hotel Booking Management System

This is a pure JavaScript based project. It is a practice project aiming to understand array methods, ES6 Javascript, and OOPS Concepts.

## About the Project

Hotel Booking Management System focuses on using array methods along with OOPS Concepts. The project is basically made by me in order to get full grip on various important JavaScript topics.

## Features

- Creating Multiple Bookings
- Checking certain conditions for bookings
- Displaying bookings according to conditions
- Sorting bookings accordingly

## Technologies Used

- JavaScript
- HTML

## How It Works

Hotel Booking Management System works on pure JavaScript console. Multiple books are made through predefined objects. The various steps are provided in comments and one by one each step is performing the required operation.
